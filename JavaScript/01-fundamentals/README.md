# JavaScript Fundamentals

## 1. Introduction

JavaScript is a programming language primarily used to build interactive and dynamic web applications.

## 2. My First JavaScript Program

```javascript
console.log("Hello World!");

let name = "Sai";

console.log("Welcome back to JavaScript, " + name);
```

## 3. Output

```text
Hello World!
Welcome back to JavaScript, Sai
```

## 4. Key Learnings

- `console.log()` is used to display output.
- `let` is used to declare a variable.
- Strings represent text values.
- JavaScript can be executed using Node.js.

## 5. Execution Command

```bash
node HelloWorld.js
```
